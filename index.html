Design and Implementation of a Hostel/Accommodation Finder with Geo-location Mapping

Heritage Polytechnic has no on-campus hostel facilities, so every student must independently source accommodation around Ikot Udota, Eket. This project digitises that search: agents list verified rooms with exact coordinates, students filter by budget and distance to campus on an interactive map, and an admin layer keeps listings and agents accountable.
